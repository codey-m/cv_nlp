Unit 2 synthesis

What is it actually rewarded for?

1 · Act

Buy the cheapest color photo printer and ship it to Emily.

A shopping page’s raw HTML can run past 100,000 tokens, and it hides the layout.

What changedThe agent sees the page as people do and points by number. Swap clicks for motor commands and the same recipe drives a robot: a vision-language-action model.

2 · Plan

It opens the $89 printer, then stalls. Nothing says what comes next.

Each click is chosen from the current screen alone, so nothing carries the order past the product page.

What changedPlanning and acting are split. A planner breaks the request into steps, and an executor turns each step into clicks on the screen.

3 · Ask

Emily’s photo shows two addresses. Which one gets the printer?

One reading of the photo gives one answer, with no sign that another reading would differ.

What changedAgreement across samples measures how sure the agent is. When the samples split, it asks a person instead of guessing.

4 · Remember

Twelve screens later, at checkout, Emily’s answer is buried.

A longer context costs more at every step and still buries the one line that matters.

What changedThe agent keeps one internal state and rewrites it at every step, so memory stays the same size. What to keep is learned from the reward for the finished task.

5 · Reward

The agent takes 12 clicks to finish. To improve it, we need to know which clicks were good.

Copying recorded clicks breaks as soon as the agent strays from the person’s path.

What changedReinforcement learning needs no step labels, only a reward for the whole attempt.

6 · Baseline

The agent tries the task four times and earns 0.6, 0.7, 0.5 and 0.6.

More attempts average out the noise only slowly.

What changedOnly attempts that beat expectation are reinforced. GRPO takes the average over a group of attempts at the same task.

7 · Hack

To give reward faster, it now checks only that an order confirmation appears.

A reward that checks less is easier to earn the wrong way.

What changedModels maximize the reward, not the goal. A rule that checks the whole order leaves fewer loopholes, and simple rule-based checks like this often match a learned reward model.
